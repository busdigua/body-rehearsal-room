# 身体排练室

把训练，排成一场好戏。

身体排练室是一款单页健身互动作品。它把训练拆成一幕幕可编排的动作，让动作演示、动作要点和训练计时出现在同一个页面。

## 功能

- 12 套训练预设，可按目标筛选，也可以抽取一套开始练习。
- 可编辑节目单，安排动作顺序和每一幕的时长。
- 训练时直接查看循环动作演示与动作提示。
- 深蹲、俯卧撑、臀桥和平板支撑提供摄像头姿态提示。
- 支持多种视觉主题，并保存个人节目单。

## 使用

直接在浏览器中打开 `index.html` 即可体验基础页面。摄像头识别需要浏览器摄像头权限和网络连接，以加载姿态识别资源。

## 文件

- `index.html`：完整的单页应用。
- `cover.svg`：作品封面图。
